NVIDIA Workshop Prep Resources

Knowledge

Talk 1: LLM Lifecycle (Pre-training to Alignment)

  • Blog: “RLHF: Reinforcement Learning from Human Feedback” — Chip Huyen (2023) Best single-article overview of the RLHF pipeline. Use for: understanding post-training alignment conceptually.
  • Paper: “Training language models to follow instructions with human feedback” — Ouyang et al. (2022) The InstructGPT paper. Foundational for understanding SFT → RM → PPO pipeline.
  • Paper: “Direct Preference Optimization” — Rafailov et al. (2023) DPO as simpler alternative to PPO. NVIDIA likely uses this. Use for: understanding modern alignment without RL.
  • NVIDIA NeMo Framework Documentation NVIDIA’s end-to-end LLM training framework. The speaker (Fiameni) likely references this.
  • Blog: “Megatron-LM: Training Multi-Billion Parameter Language Models” — NVIDIA (2024) NVIDIA’s parallelism strategies (tensor, pipeline, sequence, expert). Use for: understanding NVIDIA’s pre-training stack.
  • Paper: “Scaling LLM Training to Thousands of GPUs with NeMo” — NVIDIA (2024) NeMo + Megatron integration. Directly relevant to Gabriel’s DDP/FSDP experience.

Talk 2: Inference Optimization & Compression

  • NVIDIA TensorRT-LLM Documentation Primary reference for LLM-specific inference optimization. Use for: understanding KV-cache, in-flight batching, paged attention.
  • Blog: “NVIDIA TensorRT-LLM Supercharges Large Language Model Inference” (2024) High-level overview of TensorRT-LLM vs classic TensorRT. Use for: understanding the architectural differences.
  • Paper: “Efficient Memory Management for Large Language Model Serving with PagedAttention” — Kwon et al. (2023) vLLM paper. PagedAttention is now in TensorRT-LLM. Use for: understanding memory-bound LLM inference.
  • NVIDIA ModelOpt Documentation PTQ and QAT for LLMs. Gabriel already knows ModelOpt — focus on LLM-specific quantization (FP8, AWQ, SmoothQuant).
  • Paper: “FP8 Formats for Deep Learning” — Micikevicius et al. (NVIDIA, 2022) Hopper FP8 format specification. Use for: understanding E4M3 vs E5M2 trade-offs.
  • Blog: “NVIDIA Blackwell Architecture” (2024) FP4 support, transformer engine updates. Use for: what’s coming next in reduced precision.

Talk 3: Physical AI & World Foundation Models

  • NVIDIA Cosmos Documentation NVIDIA’s world foundation model platform. Use for: understanding what “world model” means in NVIDIA’s stack.
  • Paper: “Cosmos World Foundation Model Platform for Physical AI” — NVIDIA (2025) The Cosmos technical report. Primary source for Talk 3.
  • NVIDIA GR00T Blueprint Humanoid robot foundation model. Use for: understanding embodied AI in NVIDIA’s roadmap.
  • NVIDIA Isaac Sim Documentation Simulation platform for robotics. Use for: understanding the sim-to-real pipeline.
  • NVIDIA Omniverse Documentation USD-based 3D simulation platform underlying Isaac Sim and Cosmos. Use for: understanding the infrastructure layer.
  • Blog: “What Is Physical AI?” — NVIDIA (2025) Jensen Huang’s framing of Physical AI as the next wave. Use for: understanding NVIDIA’s strategic narrative.

Wisdom (Communities)

  • NVIDIA Developer Forums — TensorRT-LLM Active community for TensorRT-LLM issues. Use for: understanding real deployment pain points.
  • r/LocalLLaMA Practical LLM inference optimization community. High signal on quantization trade-offs.

Gaps

  • No public benchmarks comparing TensorRT-LLM FP8 vs FP4 on Blackwell for long-context (>128k) workloads
  • Cosmos is very new (2025) — limited independent analysis exists
  • Speaker-specific publications for Habert and Mohan not yet identified
