One lemma does all the work: Var(Σ wixi) = n · Var(w) · E[x²]. Xavier, He, the 1/√dk in attention and the classic sharded-initialization bug are all applications of it.

1. Why scale compounds

For a plain MLP, hl = f(Wlhl−1). If each layer multiplies the signal's mean square by a factor c, then after L layers the factor is cL:

0.9100 ≈ 2.66 × 10−5   |   1.1100 ≈ 1.38 × 104

The same applies backward to gradients. Initialization aims for c ≈ 1 in both directions at step 0.

Symmetry: all-zero (or all-equal) weights give identical rows, identical outputs and identical gradients, so the neurons never differentiate. Weights need random, zero-mean initialization. Biases at zero are fine. Deliberately zero-initializing a final projection in a residual branch is a different, intentional trick (Section 7, Lesson 8).

2. The variance lemma

Let z = Σi=1n wixi. The wi are i.i.d. with E[w] = 0 and independent of x. The xi may have any mean.

E[z] = Σ E[wi] E[xi] = 0
Var(z) = E[z²] = ΣiΣj E[wiwj] E[xixj] = Σi E[wi²] E[xi²]
Var(z) = n · Var(w) · E[x²]

The cross terms vanish because E[wiwj] = E[wi]E[wj] = 0 for i ≠ j.

Two nuances that impress interviewers:
  1. E[x²], not Var(x). They coincide only if E[x] = 0, which holds for tanh and linear layers but not for ReLU or sigmoid outputs. Writing Var(x) is the most common whiteboard mistake.
  2. Correlated inputs do not break the lemma at init. The independence of the weights kills the cross terms. For a fixed input, VarW(z) = Var(w)·‖x‖², so the quantity being propagated is the mean square ‖x‖²/n.

3. Forward and backward conditions

Notation: yl = Wlxl−1, xl = f(yl). Wl has shape (nout, nin), like nn.Linear.weight.

3.1 Forward (linear regime, e.g. tanh near 0, where f(y) ≈ y and f′(0) = 1)

Var(yl) = nin · Var(Wl) · Var(yl−1)  ⇒  nin · Var(W) = 1

3.2 Backward

∂L/∂xl−1 = WlT (∂L/∂yl),    ∂L/∂yl = (∂L/∂xl) ⊙ f′(yl)
Each component of WTg sums over nout terms ⇒ Var(∂L/∂xl−1) = nout · Var(W) · E[(∂L/∂yl)²]
With f′ ≈ 1:  nout · Var(W) = 1

3.3 Weight gradients

∂L/∂Wl = (∂L/∂yl) xl−1T  ⇒  Var ≈ E[xl−1²] · E[(∂L/∂yl)²]

If both conditions held, activations and back-propagated gradients would have equal scale in every layer. Weight gradients would then also be comparable across layers, so a single learning rate fits all of them.

4. Glorot/Xavier: the compromise

Both conditions can only hold together if nin = nout. Glorot and Bengio take the harmonic mean of the two ideal variances 1/nin and 1/nout:

Var(W) = 2 / (nin + nout)

The paper's normalized initialization is the uniform form. Since Var(U[−a, a]) = a²/3:

W ~ U[−a, a],   a = √(6 / (nin + nout))

"Xavier normal", N(0, 2/(nin+nout)), is a library variant with the same variance, not the paper's formula.

4.1 The baseline it replaced

The paper's "standard" heuristic was U[−1/√n, 1/√n]. That gives Var(W) = 1/(3n), so the forward factor per layer in the linear regime is n · 1/(3n) = 1/3. After 10 layers the variance has shrunk by 3−10 ≈ 1.7 × 10−5.

4.2 Worked example: 512 → 256

Var(W) = 2/768 ≈ 2.604 × 10−3,   std ≈ 0.0510,   uniform bound a = √(6/768) ≈ 0.0884

4.3 What the paper found empirically

From the PMLR abstract:

  • The logistic sigmoid is unsuited to deep nets with random init, because its non-zero mean can drive especially the top hidden layer into saturation.
  • Saturated units can move out of saturation by themselves, but slowly. This explains training plateaus.
  • A non-linearity that saturates less (softsign) can be beneficial.
  • Training is harder when the singular values of each layer's Jacobian are far from 1. This motivates the normalized initialization, which gave substantially faster convergence.

The paper also compares cross-entropy with quadratic cost and reports fewer plateaus with cross-entropy. [verify]

5. He/Kaiming: the ReLU correction

The pre-activation y = Wx is symmetric with zero mean, because W is, even though x = ReLU(·) is not zero-mean. Therefore:

E[ReLU(y)²] = ∫0∞ y² p(y) dy = ½ E[y²] = ½ Var(y)

Plug this into the lemma (with E[x²], not Var(x)):

Forward: Var(yl) = ½ · nin · Var(W) · Var(yl−1) ⇒ Var(W) = 2 / nin,  std = √(2/nin)
Backward: f′(y) = 1[y > 0], E[f′²] = ½ ⇒ Var(W) = 2 / nout

5.1 Why choosing one fan mode is enough

Use fan_in mode (forward exact). The backward factor per layer is then ½ · nl · 2/nl−1 = nl/nl−1, which telescopes:

∏l=1L nl/nl−1 = nL/n0

The mismatch is bounded by the ratio of the first and last widths and does not compound with depth. Fan_out mode gives the mirror result: forward ratio n0/nL.

5.2 Leaky ReLU / PReLU with slope a

E[x²] = ½(1 + a²) Var(y) ⇒ Var(W) = 2 / ((1 + a²) · nin),   gain = √(2/(1 + a²))

For GELU/SiLU there is no equally clean closed form. In practice people use He- or Xavier-style scales, or a fixed small std combined with normalization (Lesson 8).

6. Gains and framework conventions

In general: Xavier std = gain · √(2/(fan_in + fan_out)), and Kaiming std = gain / √fan_mode.

SchemeDistributionPyTorchNote
Xavier uniformU(± gain·√(6/(fi+fo)))xavier_uniform_Paper's form. Keras Dense default is glorot_uniform [verify]
Xavier normalN(0, gain²·2/(fi+fo))xavier_normal_Default gain = 1. Pass calculate_gain("tanh") for tanh
He normalN(0, gain²/fan_mode)kaiming_normal_Default nonlinearity leaky_relu with a = 0, so gain = √2 (same as ReLU)
He uniformU(± gain·√(3/fan_mode))kaiming_uniform_Same variance as He normal
nn.Linear/nn.Conv* defaultU(±1/√fan_in), Var = 1/(3·fan_in)kaiming_uniform_(a=√5)Equals Glorot's "standard" baseline. Bias also U(±1/√fan_in) [verify in your version]

Gains (nn.init.calculate_gain): linear/conv/sigmoid = 1, tanh = 5/3 (heuristic), relu = √2, leaky_relu = √(2/(1+a²)), selu = 3/4. [verify selu]

Why the Linear default is ~1/(3·fan_in): gain(leaky_relu, a=√5) = √(2/6) = 1/√3, and the bound is (1/√3)·√(3/fan_in) = 1/√fan_in.

Fan computation: PyTorch uses fan_in = size(1) × receptive field and fan_out = size(0) × receptive field.

  • Linear weight (out, in): fan_in = in.
  • Conv weight (Cout, Cin/groups, kh, kw): fan_in = (Cin/groups)·kh·kw.
  • Hand-rolled code that transposes the weight silently swaps fan_in and fan_out.

7. Where the derivation breaks (bridge to Lesson 8)

7.1 Residual streams

Consider xl+1 = xl + F(xl). Suppose F preserves variance and its output is uncorrelated with xl:

Var(xl+1) = 2 · Var(xl) ⇒ 2L growth without normalization

With pre-LN, F sees a normalized input, so its output variance is roughly a constant c. Then Var(xL) ≈ Var(x0) + L·c, which is linear growth. Common fixes:

  • Scale the branch outputs, e.g. GPT-2's 1/√N on residual projections [verify].
  • Zero-initialize the last BN γ or projection in each branch [verify: Goyal et al. 2017].
  • Fixup [verify].

7.2 Attention logits

The logit q·k = Σi=1dk qiki is the same lemma. With independent unit-variance components, Var(q·k) = dk. Dividing by √dk keeps logits O(1). Otherwise softmax saturates and its gradients vanish, which is the same story as the saturated sigmoid.

7.3 Embeddings

An embedding is a lookup, not a sum, so the fan argument does not apply. A fixed small std (e.g. 0.02) is a common convention [verify]. With tied embeddings, this choice also sets the scale of the output logits.

7.4 Limits

Initialization fixes the scale at step 0 only. It does not make learning rates transfer across widths; that is a separate topic (μP [verify], out of scope).

8. Systems angle (Nvidia/Helsing relevance)

8.1 The sharded-initialization trap

In tensor parallelism with degree p, a weight W of shape (out, in) is split across devices:

  • Column-parallel splits out: the shard is (out/p, in). fan_in is still correct, but fan_out is wrong, which breaks Xavier.
  • Row-parallel splits in: the shard is (out, in/p). Calling kaiming_normal_ on the local shard computes fan_in = in/p, so the std is too large by √p.

Fixes:

  • Compute the std from the global shape and call normal_(0, std) on the shard.
  • Or initialize the full tensor and scatter it, at the cost of extra memory.

RNG streams also need care:

  • Tensor-parallel shards need distinct streams.
  • Data-parallel replicas need identical streams.

Megatron-LM handles this with a model-parallel RNG tracker [verify].

8.2 Meta-device / deferred init

Large models are often built on the meta device and materialized per shard. Make sure reset_parameters or your init function sees global shapes or uses an explicit std. Check the exact behavior of your FSDP version. [verify]

8.3 Low precision (link to Lessons 1 and 5)

  • Sampling: sample in FP32, then cast.
  • BF16: rounds each weight with relative error ≤ 2−8. The distribution survives and the range is no issue.
  • FP16: a typical std of ~0.02 is far above the minimum normal of 6.1×10−5, so it is fine.
  • FP8 E4M3: the minimum normal is 2−6 ≈ 0.0156. With He init at fan_in 4096 (std ≈ 0.0221), about 52% of weights fall below it, and ~3.5% flush to zero. This is why FP8 needs per-tensor or block scaling.

8.4 Step-0 health check

  • Log the per-layer activation RMS and the ratio RMSl/RMSl−1.
  • Log the per-layer gradient RMS.
  • Healthy: O(1) values and flat across depth.
  • A geometric trend means an init, fan, gain or residual-scaling bug. Find it before touching the optimizer.

9. Lab (~40 min)

Write down a prediction for each printed row before running. Requires PyTorch ≥ 2.1 for Part 5.

import math
import torch
import torch.nn as nn

torch.manual_seed(0)

INITS = {
    "N(0,1)":        lambda W: nn.init.normal_(W, 0.0, 1.0),
    "N(0,0.01)":     lambda W: nn.init.normal_(W, 0.0, 0.01),
    "xavier":        lambda W: nn.init.xavier_normal_(W),
    "xavier+tanh":   lambda W: nn.init.xavier_normal_(W, gain=nn.init.calculate_gain("tanh")),
    "he":            lambda W: nn.init.kaiming_normal_(W, nonlinearity="relu"),
    "torch_default": lambda W: nn.init.kaiming_uniform_(W, a=math.sqrt(5)),
}

def probe(act, init_fn, depth=50, width=512, batch=256):
    """Plain MLP at init: per-layer activation RMS and input-gradient RMS."""
    x = torch.randn(batch, width, requires_grad=True)
    h, rms = x, []
    for _ in range(depth):
        W = init_fn(torch.empty(width, width))      # (out, in), like nn.Linear
        h = act(h @ W.T)
        rms.append(h.pow(2).mean().sqrt().item())
    h.backward(torch.randn_like(h))                 # unit-variance upstream gradient
    return rms, x.grad.pow(2).mean().sqrt().item()

# Part 1: depth sweep
for act_name, act in [("tanh", torch.tanh), ("relu", torch.relu)]:
    print(f"\n== {act_name} ==")
    for name, fn in INITS.items():
        rms, g = probe(act, fn)
        print(f"{name:14s} RMS L1={rms[0]:9.3e} L10={rms[9]:9.3e} "
              f"L50={rms[-1]:9.3e} | input-grad RMS={g:9.3e}")

# Part 2: nn.Linear default equals Glorot's "standard" baseline
lin = nn.Linear(1024, 1024)
print("\nnn.Linear Var(W):", lin.weight.var().item(), " 1/(3*fan_in):", 1 / (3 * 1024))

# Part 3: sharded-init trap (row-parallel, tp=4)
out_f, in_f, tp = 4096, 4096, 4
std_full = nn.init.kaiming_normal_(torch.empty(out_f, in_f), nonlinearity="relu").std().item()
std_naive = nn.init.kaiming_normal_(torch.empty(out_f, in_f // tp), nonlinearity="relu").std().item()
std_fixed = torch.empty(out_f, in_f // tp).normal_(0, math.sqrt(2 / in_f)).std().item()
print(f"full={std_full:.4f}  naive shard={std_naive:.4f} (x{std_naive / std_full:.2f})  "
      f"fixed shard={std_fixed:.4f}")

# Part 4: attention scaling is the same lemma
d = 128
q, k = torch.randn(100_000, d), torch.randn(100_000, d)
s = (q * k).sum(-1)
print(f"Var(q.k)={s.var().item():.1f} (d={d})  after /sqrt(d): {(s / math.sqrt(d)).var().item():.3f}")

# Part 5 (stretch): He-init weights cast to FP8 E4M3
W = nn.init.kaiming_normal_(torch.empty(4096, 4096), nonlinearity="relu")
W8 = W.to(torch.float8_e4m3fn).float()
print(f"std={W.std().item():.4f}  below E4M3 min normal: "
      f"{(W.abs() < 2**-6).float().mean().item():.1%}  flushed to 0: "
      f"{(W8 == 0).float().mean().item():.1%}")
Expected behavior (open after running)

Part 1, ReLU:

  • he stays flat.
  • xavier loses a factor ½ in variance per layer (RMS × 0.707, so ~3×10−8 at L50).
  • torch_default loses a factor 1/6 per layer.
  • N(0,0.01) vanishes: variance factor ½·512·10−4 ≈ 0.026 per layer.
  • N(0,1) grows ~16× in RMS per layer and overflows to inf/NaN around layer 32.

Part 1, tanh:

  • N(0,1) saturates (RMS near 1) and its gradients are unreliable.
  • N(0,0.01) and torch_default vanish.
  • xavier decays slowly because tanh contracts.
  • xavier+tanh (gain 5/3) holds much steadier.

Part 2: both values ≈ 3.26×10−4.

Part 3: the naive shard ratio is ≈ 2.00 = √4.

Part 4: ≈ 128, then ≈ 1.

Part 5: ~52% below min normal, ~3.5% zero.

10. Interview drills (~15 min)

10.1 Thirty-second answer

"For y = Σ wixi with zero-mean independent weights, Var(y) = n·Var(w)·E[x²]. Preserving the forward signal needs nin·Var(W) = 1. The backward pass goes through Wᵀ, so it needs nout·Var(W) = 1. Glorot and Bengio compromise with 2/(nin+nout), uniform bound √(6/(nin+nout)), derived in tanh's linear regime. ReLU zeros half of a symmetric pre-activation, so E[x²] = ½Var(y), and He uses 2/nin. In practice I check fans on sharded weights, the gain for the nonlinearity and residual-branch scaling, and I verify by logging per-layer activation RMS at step 0."

10.2 Whiteboard prompts

Derive He initialization. Where exactly does the ½ come from?

y = Wx is symmetric with zero mean over W, so E[ReLU(y)²] = ½E[y²]. The lemma uses E[x²], giving Var(yl) = ½·nin·Var(W)·Var(yl−1) and therefore Var(W) = 2/nin. Using Var(x) instead of E[x²] gives the wrong answer.

Leaky ReLU with slope 0.2: what is Var(W)?

2/((1 + 0.04)·nin) = 1.923/nin.

Why is the PyTorch Linear default "too small" for a deep ReLU MLP without normalization?

Var = 1/(3·fan_in). With ReLU, the per-layer variance factor is ½·1/3 = 1/6, so the signal vanishes geometrically. It works in practice because modern nets use normalization and residuals.

At step 0, the residual-stream RMS of your 48-block transformer grows ~1.4× per block. What do you check?

1.4² ≈ 2, which is the 2L signature of an unnormalized residual stream with variance-preserving branches. Check in this order:

  1. Is the norm placement what you think (pre- versus post-LN)?
  2. Are the branch output projections scaled down or zero-initialized?
  3. Are fans computed from global shapes on sharded weights?
  4. Are the correct gains used?
A row-parallel layer was initialized with kaiming_normal_ on each shard (tp = 8). What is the effect and the fix?

fan_in is computed as in/8, so the std is √8 ≈ 2.83× too large. Fix: use std = √(2/inglobal), or initialize the full tensor and scatter it. Also check the RNG stream policy: distinct across TP shards, identical across DP replicas.
