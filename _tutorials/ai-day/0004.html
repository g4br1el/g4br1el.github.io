Talk 1: LLM Lifecycle (14:30–15:15)

Speaker: Dr. Giuseppe Fiameni (NVIDIA Solution Architect)

Key Terms to Recognize Instantly

Pre-training
Next-token prediction on ~15T tokens → base model. 99% of total compute.
SFT
Supervised fine-tuning on (instruction, response) pairs. 10k–100k examples.
RLHF
Train reward model on preferences → optimize policy via PPO. 4 models in memory.
DPO
Skip reward model. Direct loss on preference pairs. Simpler, stable, offline.
Megatron-LM
NVIDIA's 5D parallelism (TP+PP+DP+SP+EP). TP intra-node (NVLink), PP inter-node.
NeMo
End-to-end LLM framework: data curation → training → alignment → export.
NeMo-Aligner
PPO/DPO orchestration. Handles multi-model interleaved generation + training.
Transformer Engine
FP8 training on Hopper. Delayed scaling. Drop-in for nn.Linear.
MFU
Model FLOPs Utilization. Frontier target: 40–55% on H100 clusters.

Talk 2: Inference Optimization (15:30–16:30)

Speaker: Dr. Séverine Habert (NVIDIA)

Key Terms to Recognize Instantly

Prefill
Process all input tokens in parallel. Compute-bound. Metric: TTFT.
Decode
Generate 1 token per step. Memory-bandwidth-bound. Metric: TPS.
KV-Cache
Stored K,V from past tokens. Grows linearly with seq len. Llama-70B: ~2.6 MB/token.
Paged Attention
Non-contiguous KV pages (like OS virtual memory). Near-zero fragmentation. From vLLM.
In-flight Batching
Insert/remove requests every iteration. GPU always full. 2–5× over static.
Speculative Decode
Small draft model → K candidates → big model verifies in 1 pass. Trades compute for latency.
CUDA Graphs
Capture decode step as single GPU graph. Eliminates per-kernel launch overhead.
FP8 (Hopper)
E4M3 fwd, E5M2 grad. 2× throughput vs FP16. Negligible accuracy loss.
FP4 (Blackwell)
2× over FP8. Weights-only for now. Native Tensor Core support.
AWQ
Weight-only INT4. Protect salient weights (by activation magnitude).
SmoothQuant
Migrate quant difficulty: divide activations, multiply weights by same factor.
2:4 Sparsity
2 zeros per 4 weights. HW-native on Hopper/Blackwell. 2× compute, ~0 accuracy loss.
FlashAttention
Tiled attention in SRAM. Never materializes seq×seq matrix. O(seq) memory.
TensorRT-LLM
NOT classic TensorRT. Python model def → Executor (scheduler + KV mgmt + TP).
NIM
Pre-optimized Docker containers. "docker run" optimal inference.

The Decode Bottleneck (memorize this)

70B FP16 → load 140 GB weights per token. H100 = 3.35 TB/s → minimum ~42 ms/token at batch=1.
Arithmetic intensity ≈ 1 FLOP/byte. Need ~1181 for compute-bound. GPU compute is ~99% idle during single-request decode.
→ Quantization reduces bytes loaded. Batching amortizes weight loads.

🧠 Mental Models to Keep Loaded

LLM Training Pipeline

Pre-train (15T tok, 99% compute) → SFT (100k examples) → Align (DPO/RLHF)
Megatron-LM → NeMo → NeMo-Aligner → TensorRT-LLM (export)

LLM Inference: Two Phases

PREFILL: all input tokens in parallel → compute-bound → metric: TTFT
DECODE: 1 token/step, load all weights → bandwidth-bound → metric: TPS
Optimization: quantize (reduce bytes) + batch (amortize loads) + speculate (skip steps)

Physical AI Loop

Real video → Cosmos (learn physics) → generate scenarios
Isaac Sim (precise physics) → train policy (GR00T) → domain randomization
Deploy to Jetson Thor (edge, quantized) → act in real world
